# Data Analysis & Manipulation with Pandas

This repository contains practical workflows, exploratory data analysis (EDA), and data manipulation routines using the **Pandas** library in Python.

## Overview

The primary focus of this repository is building an intuitive and efficient data manipulation pipeline. Working with tabular data structures is a critical foundation for both applied mathematics and predictive machine learning models.

## Key Concepts & Operations Covered

- **Core Data Structures:**
  - Creating and working with Pandas `Series` and `DataFrame` objects.
  - Custom index alignment and column manipulation.
- **Data Preprocessing & Cleaning:**
  - Handling missing data (`NaN` values, imputation, drop operations).
  - Data type conversions and formatting.
- **Indexing, Selecting & Filtering:**
  - Conditional data filtering and logical masking.
  - Positional and label-based indexing using `.loc[]` and `.iloc[]`.
- **Aggregation & Grouping:**
  - Descriptive statistics (`mean`, `median`, `std`, `describe`).
  - Split-apply-combine workflows using `groupby()`.

## Tools & Libraries

- **Language:** Python 3.x
- **Core Library:** Pandas
- **Supplementary Tools:** NumPy, Jupyter Notebooks
